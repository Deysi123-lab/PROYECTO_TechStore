# S16 - Evaluación final

## Criterios de evaluación

| Criterio | Evidencia en TechStore |
|---|---|
| Arquitectura distribuida | Config + Eureka + Gateway + microservicios |
| Seguridad | JWT en auth y gateway |
| Resiliencia | Circuit Breaker producto → catalogo |
| Mensajería | Kafka pedido → pago |
| Observabilidad | Prometheus + Grafana + Loki |
| Frontend | Angular integrado vía proxy |
| Reproducibilidad | Docker Compose + Guia.txt |

## Demostración individual

Cada estudiante debe poder:

1. Levantar su componente sin ayuda.
2. Ejecutar una prueba concreta de su módulo.
3. Explicar cómo se conecta con el resto del sistema.
4. Interpretar logs o métricas de su servicio.

## Entregables

- Repositorio con rama `PROYECTO_TechStore` (código)
- Rama `gh-pages` (documentación web)
- Evidencias de pruebas en `PRUEBAS.md`
- Defensa grupal con nota individual
